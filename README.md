# Back-Propagation

A .NET Framework 4.8 Windows Forms demonstration of a neural network trained with backpropagation.

## Running the project

1. Open `Back Propagation.slnx` in Visual Studio.
2. Build the solution with `Ctrl+Shift+B`.
3. Run with `F5`.
4. Use the default training parameters or enter custom values.
5. Click **Run training** to generate data, train the network, and display accuracy and learned weights.

The demo uses a 4-input, configurable-hidden-node, 3-output network with synthetic data split into training and test sets.
